## 本次简化后的产品行为

- 自动更新默认开启：在线 agent 首次启动整理一次，此后每小时更新 `.hop/handoff.md`，完成后直接在 Portal 展示，无需人工确认。
- Portal 只提供「自动更新简报」开关、内容、更新时间及原有手动编辑，没有简报任务列表；主人维护任务也不会混入来访记录。
- 关闭开关保留已有简报，停止后续更新；已开始的一次允许完成。开关持久化，agent 每 5 秒读取；关闭 Portal 页面或进程不停止在线 agent 的调度。
- 保存下次执行时间，重启不立即重复刚开始的更新；错过多个小时只执行一次，不补跑所有历史周期。单次失败仍按小时重试，避免持续调用模型。
- 更新插件和控制台并重启 agent 后生效；旧 Portal 的同目录、同标题、已知提示词的简报任务会由新插件清理，避免与新开关同时运行。
