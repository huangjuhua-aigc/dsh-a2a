# Microsandbox 接入验收（2026-10-30）

环境：Windows 11 x64、WHP、Node.js 24.19.0、Microsandbox 0.7.11。使用临时公共资料、访客目录、协议状态与合成凭据；没有调用付费模型或切换用户正在运行的服务。

## 实测结果

| 检查 | 结果 |
| --- | --- |
| 公共文件通过 Python 覆盖、追加、删除、重命名，以及创建公共文件 | 全部拒绝；宿主原文件内容不变 |
| 自己的 /work 创建、修改、重命名、删除 | 成功 |
| Alice / Bob 的私有文件 | 分离；各自仅可读取自己的持久化文件 |
| 后端聊天记录、Docker socket、宿主环境凭据 | 未暴露 |
| 网络连接 | 禁止 |
| 硬链接、Windows junction、越界路径 | 拒绝，包括 VM 已存在后新增的链接 |
| 中止运行中的 Python | 调用结束，后续工具仍可使用 |
| 公共资料更新 | 下一工具调用可见新副本，私有文件仍在 |
| 暂停、恢复、停止、控制器重建 | 私有文件均保留 |
| 遗留暂停 VM 回收 | 新控制器停止旧实例，再以原盘启动 |
| 真实 A2A → DSH 模型工具调用 → Microsandbox → A2A 答复 | 通过；公开工具列表仍仅 read_file |
| 新 DSH profile 自动安装插件、准备 runtime、再次启动复用 | 通过；无需用户手动安装 Microsandbox |

完整真实计时测试观察到：最后一次工具调用完成后 **31178 ms 暂停、600316 ms 停止**。定时器每秒检查，调度存在少量误差。停止后再读取 /work/persist.txt，内容仍完整。该测试没有缩短 30 秒或 10 分钟阈值。

## 自动化验证

- dsh-a2a：232 项常规测试通过；TypeScript 检查、构建、仅使用声明运行依赖的包导入检查通过。
- 原生 Microsandbox：8 项不同用例通过。其中快速运行通过 7 项，完整计时运行单独验证第 8 项（其余重叠用例同样通过）。
- Portal：18 项后端/安装/启动参数测试通过，包括真实首次安装和缓存复用。
- Portal UI：34 项通过（31 项常规与沙箱界面用例，另以正确的独立 Relay checkout 跑过 3 项中继用例）。覆盖进度、禁止重复点击、虚拟化缺失提示、失败重试、简报和邀请回归。
- npm dry-run 包检查确认包含 Python worker、运行环境准备器、执行器及生命周期管理器；未发布 npm。

代码含可复跑测试：dsh-a2a 的 pnpm test:microsandbox，以及 Portal 的 tests/visitor-runtime.integration.test.ts。完整 10 分钟用例需设置 A2A_MSB_WALLCLOCK=1；真实安装用例需设置 A2A_HOST_RUNTIME_TEST=1。见各仓库测试说明。

## 范围

本次验收针对 Windows x64。macOS、Linux、Windows ARM64 未实测。暂停会保留主要内存，停止才释放运行资源。私有文件留在本机的访客专用虚拟磁盘中，不同步回旧宿主目录。文件导出/下载 UI 与公开 Python/写文件工具未在本次开放。无法静默替用户启用系统虚拟化、获取管理员权限或重启系统。
