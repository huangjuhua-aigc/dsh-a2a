# 公网访问修复与迁移

本次修复对应 `review-2026-10-24-public-access.md` 的 9 个代码问题，同时修改了配套仓库 `D:\code\Talk2MyAgent\packages\a2a-host`。

## 权限与入口

- 访客可以聊天、读取开场简报，并通过 `read_file` 读取用户指定工作目录的数据。默认读取范围为 `isolation.workspaceRoot`；配置 `peerWorkspaces.<访客>` 时，该访客只读取其专属目录。相对路径从这个资料目录解析，不从自动创建的访客 cwd 解析。
- 访客使用独立的公共系统提示词，并关闭可选的宿主运行时上下文，避免继承主人的个性化提示、工作区资料和记忆。宿主插件仍是可信代码；不要在公共部署中挂载会强制向模型注入私人资料的自定义插件。
- 只注册受控的 `read_file`，屏蔽宿主其他工具；写文件、执行命令、网络及跨会话工具暂不开放。文件读取会校验规范化真实路径，并拒绝目录外路径、符号链接/junction、硬链接、Windows ADS 和设备路径。插件自身的状态目录即使放在工作目录内也不开放。
- `read_file` 支持 UTF-8 文本和目录列表：`path: "."` 查看资料目录，`offset`/`limit` 按行或目录项分页。单文件上限 2 MiB，单次返回最多 32000 字符、500 行/项，单次目录扫描最多 1000 项。二进制文件及 PDF/Office 内容提取尚未实现。
- `per-peer` 和 `read-only` 仍不构成 OS 级读取隔离；这里的读取边界由专用工具执行。工作目录内的资料会提供给获准访客，因此应选定可分享的数据目录。以后新增工具时逐项设计权限，命令执行等能力仍需独立隔离环境。
- 主人 RPC 与监控迁到 Windows 命名管道或 Unix socket，仍要求 admin token。公网 TCP 入口既不接受主人凭据，也不挂载监控路由。主人维护简报的工具权限属于可信本机管理功能。
- `trustedPeers` 未填写表示允许已配置且通过认证的访客；`[]` 表示全部禁止。获准访客可以对话并使用受限的 `read_file`，不会获得其他工具。控制台文案与此保持一致。

## 资源与任务行为

| 限制 | 默认值 |
| --- | --- |
| 全局/每访客并发任务 | 8 / 2 |
| 每访客每日任务数 | 200，按 UTC 日持久化 |
| 常驻会话数 | 64；满时先回收空闲会话，全部忙碌则拒绝 |
| 任务执行时限 | 120 秒 |
| 每任务模型请求次数 | 8 |
| 每次请求输出 token 上限 | 4096 |
| 单条输入/任务输出字符上限 | 32000 / 64000 |
| 每任务 SSE 订阅/缓冲上限 | 4 / 256 KiB |
| SSE 心跳 | 15 秒 |
| 结果保留时间/会话总数/单会话 checkpoint | 24 小时 / 256 / 4 MB |

超出准入限额返回 429；同一 context 并发提交返回 409，避免串答。执行超时主动取消 agent；取消尚未完成时仍占用额度。模型适配器必须响应 AbortSignal，生产环境另需进程级监护。这些限制控制工作量，不代表精确的金额封顶，供应商账户仍应配置消费额度。

任务结果独立于常驻 agent 保留；会话被回收后可查询任务，并在保留期内用同一 contextId 继续对话。冷恢复创建新的 harness session，保留对话历史、身份归属和轮数。重启时未完成任务标记为 failed，不自动重新执行。磁盘写入失败时拒绝继续该会话并报告失败；恢复磁盘后检查运行日志。

SSE 断线立即释放订阅与心跳。超过缓冲上限会断开流，客户端仍可用 GetTask 查询。messageId 暂不提供幂等语义：隧道/中继不能自动重放 SendMessage。

## 升级现有部署

1. 两个仓库的修改需要一起部署。构建本插件并更新对应 DSH profile 中安装的插件；本次源代码修改不会自动替换已经运行的实例。
2. 控制台更新后，重新保存 agent 配置，生成含 `admin.socketPath` 的 patch；再重启该 agent。旧控制台通过 HTTP 的主人/监控请求将失效。
3. 检查访客的“允许对话和读取工作目录”勾选，尤其是此前所有 `trusted` 均为 false 的配置：升级后它会正确地拒绝所有访客。原先指定的工作目录继续作为资料目录，不必把所有资料改写成简报。
4. 公网地址填完整 HTTPS 域名，控制台补齐 `/a2a`，并让域名模式默认绑定 127.0.0.1。隧道目标指向实际端口，例如 `http://127.0.0.1:3080`；有路径前缀时需在代理中映射回本地 `/a2a`。Tailscale/局域网直接连接须使用本机确实存在的网卡 IP；失效 IP 不会自动改绑其他网卡。
5. 状态目录默认在用户主目录的 `.dsh-a2a` 下，包含会话文本，应使用当前系统账户的私有目录。同一状态目录禁止多进程同时使用。备份和日志也按私人数据处理。

本次没有发布 npm 包、改写已保存的真实凭据、重启正在运行的服务或配置公网隧道。现有 DSH 中文流解码缺陷的孤立代理项防护继续保留。
